Tasmanian Inland Fishing Code
The Tasmanian Inland Fishing Code is produced every year. It is a summary of the recreational fishery regulations. It is essential reading for licensed freshwater anglers.
Please download a copy of the current Tasmanian Inland Fishing Code below.
